# n8n Automation & Supply Chain Labs

Репозиторій із практичними сценаріями автоматизації бізнес-процесів та складської логіки на базі **n8n**.

## Виконані лабораторії

### 01. Контроль критичних залишків складу (`01_inventory_check.json`)
* **Бізнес-задача:** Автоматична перевірка складських позицій на відповідність мінімальним нормам запасу, розрахунок обсягу дозамовлення до подвійної норми та генерація тексту сповіщення про дефіцит.
* **Технічний стек:** `n8n`, `JavaScript (Code Node)`, `JSON`, `Expressions`, `Conditional Logic (If)`.
* **Логіка роботи:**
  1. Ініціалізація вхідного масиву даних про залишки (`Code`).
  2. Фільтрація позицій за умовою `stock < min_norm` (`If` з типізацією `Number`).
  3. Розрахунок потреби (`min_norm * 2 - stock`) та формування динамічного повідомлення (`Edit Fields`).
